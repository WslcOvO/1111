# 短片项目

总导演：Claude｜画师：Codex｜动画师：Seedance｜制片/决策：用户

## 目录
- 00_brief       需求（片长、画幅、预算、配乐、字幕）
- 01_story       故事稿（用户确认前不画任何图）
- 02_storyboard  分镜表
- 03_prompts     所有生图/生视频提示词（带版本号）
- 04_design      设定图、样帧（用户确认画风前不画正式镜头）
- 05_keyframes   每个镜头的首尾帧
- 06_video_raw   Seedance 原始片段
- 07_post        ffmpeg / Python 后期脚本和成片
- 08_review      审核记录、抽帧检查、报价单
- logs           调用日志、花费记录

## 规矩
- 新版本存新文件（_v1, _v2 …），不覆盖、不删除旧文件。
- 提交视频前，另开 agent 只挑错不改文件；通过后报价，用户同意才提交。
- 不充值、不买额度；欠费即停，先粗剪已有片段。
- 导演看不到真正的动态、听不到声音，未看/未听的内容会明确标注。
